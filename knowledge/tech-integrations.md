# Technical integrations (SOAP, ERP Integration Service, events, OIC, HDL, outbound)

> Release: 26D · Last researched: 2026-11-25 · Status: PARTIAL

## Business purpose
Choose the right integration pattern for SCM/Procurement: inbound (REST, FBDI via ERP Integration Service, SOAP legacy), outbound (events, BICC, REST, BIP via ESS), HCM data (HDL). Oracle recommends REST over SOAP where an equivalent REST API exists (26D Procurement Integration Playbook).

## Where in Fusion (FSM)
- Review Topology (Setup and Maintenance) gives host/port for tokenized SOAP URLs.
- Scheduled Processes (Tools) for ESS jobs. Business-event enablement for Inventory: page "Manage Inventory Business Event Configurations".
- Profile option `ZCA_PUBLIC_BUSINESS_EVENTS` (default Y; N suppresses events, e.g. bulk loads) - from Sales/CX doc, SCM scope UNVERIFIED.

## Prerequisites & dependencies
- Integration user with the specific web-service privilege (below) via custom role; `ORA_FND_INTEGRATION_SPECIALIST` family per `access-and-roles.md`.
- FBDI flows: see `channel-c-fbdi-ess.md`.

### ERP Integration Service (REST `erpintegrations`)
`POST /fscmRestApi/resources/11.13.18.05/erpintegrations`, Content-Type `application/vnd.oracle.adf.resourceitem+json`. Body attributes (exact): `OperationName`, `DocumentContent` (Base64), `ContentType` (e.g. zip), `FileName`, `DocumentAccount` (e.g. `fin$/payables$/import$`), `DocumentId`, `JobName` ("package,jobDef"), `JobPackageName`, `JobDefName`, `ParameterList`, `ESSParameters`, `JobOptions` (e.g. `InterfaceDetails=1,ImportOption=Y,PurgeOption=Y,ExtractFileType=ALL`), `NotificationCode`, `CallbackURL`, `FileType` (LOG/OUT), `LoadRequestId`, `ReqstId`.
- OperationName values documented: `importBulkData`, `uploadFileToUCM`, `submitESSJobRequest`, `exportBulkData`; status via `GET .../erpintegrations/{OperationName}` (Get job details page exists).
- Unused positional params: `#NULL` in ParameterList, blank in ESSParameters. Purge: `submitESSJobRequest` JobDefName `InterfaceLoaderPurge`, ESSParameters `59,<LOAD_REQUEST_ID>,,,Y,ORA_FBDI` (returns 204).
- `CallbackURL`: customer service receiving ESS job status on completion; `#NULL` = no callback. SOAP equivalent: ErpIntegrationService `importBulkData` with `callbackURL`; SOAP also has `submitESSJobRequest` separately.
- NotificationCode: 2-digit; bell/email only for loadAndImportData, ImportBulkData, ExportBulkData, extractAndPurge.
- SCM planning publish/release: use dedicated planning REST services instead of submitESSJobRequest (26B SCM doc).

### Business events
- Subscribe ONLY in Oracle Integration (OIC); no other third-party platform (Procurement playbook). Most public events are not generated by default and must be enabled (SCM playbook); some via ERP Business Events REST API (GET/PATCH, privilege "Access FSCM Integration Rest Service" - from a 24B PPM page, UNVERIFIED for SCM 26D).
- Purchasing event "Purchase Order": raised on create/change/finally close/reopen. EventActionCode: `IMPLEMENTED`, `CO_IMPLEMENTED`, `FINALLY_CLOSED`, `FINALLY_CLOSE_REMOVED`. No separate "PO approved" event: IMPLEMENTED fires on implementation. Payload: EventActionCode, POHeaderId, OrderNumber, SoldToLegalEntityId, SoldToLegalEntityName, RequisitioningBusinessUnitId, BuyerManagedTransportationFlag, InterfaceSourceCode, POChangeOrderSequence, ChangeOrderTypeCode, ImplementationDate. Callback: SOAP PurchaseOrderService.getPurchaseOrder. Enabled by default.
- Other Procurement events (ERP Cloud Adapter page): Supplier Created Event, Supplier Updated Event (payload SupplierId, SupplierNumber), Supplier Negotiation Invitation Event, Item Supplier Association Create/Update.
- SCM events by category: Inventory (ASN Creation, Receipt Advice, Shipment Advice, Pick Confirm), Maintenance, Manufacturing, Order Management (Sales Order Notification, Order Status Updated), PLM (Item Create/Update, Change Order), Supply Chain Collaboration and Visibility (B2B Message Created). Inventory publish switch: Manage Inventory Business Event Configurations (Publish = Yes).
- Custom business events can be built in Application Composer and consumed by the adapter.
- `ErpImportBulkDataEvent`: with "Enable Callback" in the OIC invoke, raised after importBulkData completes; carries overall status, log file document ID, job/child job statuses. Not a SOAP callback URL.

### OIC ERP Cloud Adapter (what docs show)
Declarative event subscription; invoke REST business resources (parent/child, HATEOAS, DFF/EFF); ErpIntegrationService/FBDI upload (MTOM default from 25.02, SFTP, UCM upload; UCM download not supported); no SQL: use BIP report. Security policies: Username Password Token (+PGP), OAuth Auth Code, OAuth JWT User Assertion.

### HCM Data Loader (locations, workers) REST
Base `/hcmRestApi/resources/11.13.18.05/dataLoadDataSets`. Flow: action `uploadFile` (Base64 file; returns ContentId, auto-generated if absent) -> action `createFileDataSet` (`contentId` required; `fileAction` IMPORT_AND_LOAD | IMPORT_ONLY) -> poll data set by RequestId (DataSetStatusCode, LoadStatusCode) -> optional `submit` (fileAction e.g. LOAD). Child `businessObjects` with actions `submit`, `stop`, `generateFailedLinesFile`. Privileges: "Create HCM Data Loader Data Set Using REST Service", "Use REST Service - Data Load Data Sets", "Upload data for Human Capital Management file based import". SOAP legacy `importAndLoadData`(ContentId). Locations also via REST `locationsV2` (see `locations.md`).

### Outbound data choice
| Need | Use |
|---|---|
| Single/few records, on demand, near real time | REST (`q`, `fields`, `limit`, `offset`, `orderBy`) |
| Bulk scheduled / incremental to warehouse | BICC (or Data Extraction tool, which Oracle is moving to); output UCM or OCI Object Storage; default 10 h timeout per VO; use ExtractPVOs, not OTBI PVOs; not real time; UCM files purged by "BICC Delete Expired UCM Files" (default retention 90 days per extract guide) |
| Event-driven push | Business events via OIC |
| BIP | Not supported for extraction at volume; if needed wrap in custom ESS job type `BIPJobType`, fetch with `downloadEssJobExecutionDetails` (sync) or `exportBulkData` (async) |

### Paging / retry
`limit` + `offset`; response `hasMore`, actual `limit` reported by server; default cap commonly 500 rows; use `orderBy` for stable paging; `totalResults=true` optional. No documented 429/Retry-After behavior found -> use exponential backoff, never blind retry of non-idempotent POST (check state first).

## Common mistakes
- Using SOAP when a REST resource exists.
- Expecting a "PO approved" event; use IMPLEMENTED (+ getPurchaseOrder).
- Wrong positional ESSParameters / `#NULL` handling.
- Subscribing to events without enabling them.
- Calling Service Catalog with plain Basic auth.

## Channel & exact technique
- A: REST (`erpintegrations`, business resources, HDL `dataLoadDataSets`). Always `rest_describe` first.
- B: n/a. C: FBDI through `erpintegrations` (see `channel-c-fbdi-ess.md`). D: OIC console (outside Fusion) / UI for event enablement pages.

## How to verify
GET `erpintegrations/{ReqstId}` / ESS status; `Scheduled Processes` log; OIC activity stream; data set status in `dataLoadDataSets`.
